# 写作（文章、报告、邮件、说明）

| 症状 | 方法论 | 一句话解释 | 写进提示词的具体指令 |
|---|---|---|---|
| 啰嗦、读完不知道重点 | 金字塔原理（Barbara Minto） | 结论先行，上层观点概括下层，同层观点分类清楚 | 第一段直接给结论；每个分论点支撑结论；分论点之间不重叠不遗漏；每段第一句是这段的观点 |
| 邮件、汇报太绕 | BLUF（Bottom Line Up Front，结论放最前） | 第一句话就说结论和需要对方做什么 | 第一句写结论或请求；第二句写理由；细节放后面 |
| 开头没吸引力、逻辑铺垫乱 | SCQA（情境-冲突-问题-答案） | 先讲背景，再讲矛盾，引出问题，最后给答案 | 按 情境→冲突→问题→答案 组织开头，冲突要具体 |
| 读起来空洞、AI 味重 | 展示而非告知（Show, Don't Tell） | 用具体细节、例子、数字代替形容词和结论式评价 | 每个观点至少配一个具体例子或数字；删掉"非常重要""赋能""值得注意的是"这类空话 |
| 句子臃肿 | 奥威尔写作六规则（George Orwell，《政治与英语》） | 能用短词不用长词，能删就删，少用被动和行话 | 能删的词都删；不用套话和行话；句子平均不超过 25 字 |
| 读者看不懂 | 知识的诅咒（Curse of Knowledge）+ 费曼技巧 | 作者忘了读者不懂；用讲给外行的方式来写 | 假设读者是聪明的外行；术语第一次出现时解释；多用类比 |
| 观点说服力弱 | 图尔敏论证模型（Toulmin Model） | 一个完整论证包括：主张、证据、为什么证据能支持主张、反驳回应 | 每个主张配证据；说明证据和主张的关系；主动回应最可能的反对意见 |
| 读者读不下去 | 好奇心缺口（Information Gap Theory，Loewenstein） | 人发现自己"知道一点但不知道全部"时会想读下去 | 开头先抛出一个反常识的现象或问题，答案放在后面 |
| 新闻、通知类信息顺序乱 | 倒金字塔（Inverted Pyramid） | 最重要的放最前，越往后越次要 | 第一段回答 谁、什么、何时、何地、为什么；细节和背景往后放 |
| 内容记不住、传播不开 | SUCCESs 黏性原则（Heath 兄弟《让创意更有黏性》） | 简单、意外、具体、可信、情感、故事 | 核心观点压成一句话；加一个意外点；加一个具体故事 |
| 故事平淡 | 三幕结构 / 起承转合 | 开端-冲突升级-解决 | 明确主角想要什么、遇到什么阻碍、怎么解决；第二幕阻碍逐步升级 |
