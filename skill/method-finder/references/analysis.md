# 数据分析、调研、竞品分析、找原因

| 症状 | 方法论 | 一句话解释 | 写进提示词的具体指令 |
|---|---|---|---|
| 分析零散、有遗漏有重复 | MECE 原则 + 议题树（Issue Tree） | 拆问题时做到不重叠、不遗漏，层层拆成树 | 先把核心问题拆成互不重叠、合起来完整的子问题，再逐个分析 |
| 数据堆了很多，没有洞察 | "So What?"追问 | 每个发现都追问"这意味着什么、所以要做什么" | 每个数据结论后写一句"这意味着……"和"建议……"；没有含义的数据删掉 |
| 找不到问题根因 | 5 个为什么（5 Whys） | 连续追问为什么，直到找到根本原因 | 对问题连续追问至少 5 次"为什么"，每一层都要有数据或事实支撑 |
| 原因很多，理不清 | 鱼骨图（Ishikawa Diagram） | 按人、机、料、法、环、测等类别整理所有可能原因 | 按类别列出所有可能原因，再标出证据最强的 2–3 个 |
| 指标异动不知道从哪查 | 指标拆解树（如 GMV=流量×转化率×客单价） | 把总指标拆成几个相乘或相加的因子，逐个排查 | 把指标拆成乘法或加法因子，逐个对比变化幅度，定位是哪个因子导致的 |
| 数据没有参照，看不出好坏 | 对比分析（同比、环比、对照组、行业基准） | 单个数字没有意义，比较才有意义 | 每个关键数字都给出至少一个对比：去年同期、上期、行业平均或对照组 |
| 把相关当成因果 | A/B 测试 / 对照实验 | 只有控制其他变量，才能证明因果 | 区分相关和因果；需要因果结论时设计对照实验，说明控制了哪些变量 |
| 不确定性大，只给了一个数 | 蒙特卡洛模拟（Monte Carlo Simulation） | 让不确定的参数随机取值，模拟上万次，看结果的分布 | 列出不确定参数和取值范围，模拟大量次数，给出结果分布、中位数和 90% 区间 |
| 不知道哪个因素影响最大 | 敏感性分析（Sensitivity Analysis） | 每次只改一个参数，看结果变化多少 | 逐个调整关键参数 ±20%，按对结果的影响大小排序 |
| 竞品分析流于罗列 | 竞品对比矩阵 + SWOT | 在同一组维度下横向对比，再总结优势、劣势、机会、威胁 | 先定 5–8 个用户最在意的对比维度，用表格横向对比，最后给出我们该怎么做 |
| 行业分析没框架 | 波特五力模型（Porter's Five Forces） | 从现有竞争、新进入者、替代品、供应商、买方五个角度看行业 | 按五力逐一分析，每力给出强弱判断和依据 |
