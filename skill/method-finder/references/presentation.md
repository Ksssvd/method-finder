# PPT、汇报、演讲

| 症状 | 方法论 | 一句话解释 | 写进提示词的具体指令 |
|---|---|---|---|
| 整体看不出结论，像资料堆砌 | 金字塔原理（Barbara Minto） | 结论先行，以上统下，归类分组，逻辑递进 | 第一页给核心结论；每章是支撑结论的一个理由；先写大纲再写页面 |
| 每页标题只是话题，不是观点 | 行动标题 / 标题即结论（Action Title，咨询行业常用） | 每页标题写成一句完整的结论，而不是"市场分析"这种名词 | 每页标题是一句不超过 20 字的结论句；只读所有标题就能读懂整个故事 |
| 每页字太多 | 一页一观点（One Idea Per Slide）+ 论断-证据结构（Assertion-Evidence） | 一页只讲一件事：标题是论断，正文是证明它的图或数据 | 每页只有一个观点；正文优先用图表或图片，文字不超过 3 行 |
| 开场平淡、听众不关心 | SCQA（情境-冲突-问题-答案） | 用矛盾引出问题，让听众想听答案 | 开场按 情境→冲突→问题→答案 设计，冲突要和听众利益相关 |
| 听众不买账、没有感染力 | Duarte 演讲结构（Nancy Duarte《Resonate》：现状与可能的对比） | 在"现在是什么样"和"可能变成什么样"之间来回对比，最后号召行动 | 结构交替呈现 现状痛点 / 理想未来；结尾给明确的行动号召 |
| 图表看不懂 | 数据墨水比（Data-Ink Ratio，Edward Tufte） | 删掉一切不传递数据的装饰 | 去掉 3D、阴影、多余网格线和图例；只高亮需要关注的那条数据；图表标题写结论 |
| 细节太多但又不能删 | 渐进式披露（Progressive Disclosure） | 主线只放关键内容，细节放附录 | 正文只保留支撑结论必需的页面；数据细节、方法说明移到附录 |
| 页面重点不突出 | F 型阅读模式 / 视觉层级 | 重点放顶部和左侧，用大小和颜色区分主次 | 结论放左上；关键数字放大加粗；每页只有一个高亮色 |
