# 学习、讲解、教别人

| 症状 | 方法论 | 一句话解释 | 写进提示词的具体指令 |
|---|---|---|---|
| 讲解太难懂 | 费曼技巧（Feynman Technique） | 用小孩都能听懂的话讲清楚，讲不清说明还没懂 | 用初中生能懂的语言解释，不用术语；必须用的术语先解释；配一个生活中的类比 |
| 讲解跳跃、一下子太深 | 脚手架教学（Scaffolding） | 从已知出发，一步步搭到未知 | 先确认我已经知道什么，从那里开始；每次只加一个新概念 |
| 学了就忘 | 间隔重复 + 主动回忆（Spaced Repetition / Active Recall） | 隔一段时间回忆一次，比反复看更记得住 | 每讲完一部分就出题让我回忆；按 1 天、3 天、7 天安排复习 |
| 懂了但不会用 | 布鲁姆认知层级（Bloom's Taxonomy） | 学习从记住、理解，到应用、分析、评价、创造逐级升高 | 每个知识点设计应用题和分析题，而不只是概念题 |
| 练了很多没进步 | 刻意练习（Deliberate Practice，Anders Ericsson） | 针对弱点、有反馈、略超出能力的练习 | 找出我最弱的环节，设计略高于我水平的练习，每次练完给具体反馈 |
| 知识零散、连不起来 | 概念图 / 思维导图（Concept Map） | 把概念和它们之间的关系画出来 | 画出这个主题的核心概念及它们之间的关系，标出最重要的 3 个 |
